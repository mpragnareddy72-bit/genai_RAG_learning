# Generative_AI_Learning

| Thing                | What it is                                        |
| -------------------- | ------------------------------------------------- |
| **Nomic Embed Text** | Embedding model                                   |
| **Qdrant**           | Vector database                                   |
| **BM25**             | Keyword-ranking algorithm                         |
| **rank-bm25**        | Python library implementing BM25                  |
| **RRF**              | Ranking-fusion algorithm                          |
| **Reranker**         | Model/tool that re-ranks retrieved documents      |
| **Ollama Llama 3.2** | LLM                                               |
| **LangChain**        | Framework/library for connecting these components |
